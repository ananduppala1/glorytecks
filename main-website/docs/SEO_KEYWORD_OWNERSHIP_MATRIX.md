# SEO Keyword Ownership Matrix

**Contract:** [`SEO_KEYWORD_MAP.md`](./SEO_KEYWORD_MAP.md) — one page, one primary intent. This matrix applies it to **every indexable URL (656)**, taken from a crawl of the current build with live CMS data (2026-09-24). It is generated by `lib/seo/intent.ts`; the reasoning behind each cluster and action is in [`SEO_PHASE_3_FINAL_REPORT.md`](./SEO_PHASE_3_FINAL_REPORT.md).

- **CANONICAL** — "self" means the page declares exactly one canonical equal to its own URL. Verified for 656/656 pages.
- **PRIMARY INTENT** — for commercial and local pages, the query the page must own; for everything else, the question it answers.
- **COMPETING URLS** — only pages that would answer the same query for the same reason (see the report, §3). A course page and its locality landings are *not* listed as competitors of each other: `{course} course Hyderabad` and `{course} course {locality}` are different queries by contract (keyword map §4). Sibling landings of the same course *are* listed: their copy is ~55% shared.
- **RECOMMENDED ACTION** — KEEP · KEEP BOTH · REWRITE INTENT · MERGE · REDIRECT · NOINDEX · CHANGE INTERNAL TARGETING · MANUAL REVIEW. Nothing here has been applied; no page was deleted, merged or redirected in this phase.

Machine-readable, with title, H1, meta description, category, inbound/outbound link counts and click depth for every row: [`SEO_URL_INVENTORY.csv`](./SEO_URL_INVENTORY.csv).
